# Results

Every session in MAME was run with `tests/mame/run_keyfall.sh OUT` (program 893, `-bios v13`) and
`tests/mame/keyfall_test.lua` unless another script is named; the variables are the script's (tests/mame/README.md).
`versions-*.txt` give the emulator's, the programs', the floppy's, the card's and the songs' checksums of the runs
beside them. The "judged at" line of an events file is how late after its time each struck note reached the game (the
script strikes a key on the first MAME frame at which the game's clock has passed the note's time, so up to one frame,
17 ms, of it is the script's); the "accompaniment" line is how long after the game put a message into MIDI IN 1's ring
the firmware read it (write taps on the ring's header).
